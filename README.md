## 📥 Installation

### Method 1: Clone the Repository

```bash
# Clone the repository
git clone https://github.com/Qureshi-Ubaid/Blogging-Website.git

# Navigate to the project directory
cd Blogging-Website

# Open in your browser
# Using Python (Python 3)
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Or simply open index.html in your browser
open src/index.html
```

### Method 2: Download ZIP

1. Click the green "Code" button
2. Select "Download ZIP"
3. Extract the folder
4. Open `src/index.html` in your browser

## 🚀 Usage

### Creating a Blog Post

1. Navigate to the blog creation page
2. Fill in the post title, content, and category
3. Click "Publish" to save the post
4. View your post on the blog feed

### Reading Blog Posts

1. Visit the home page to see all published posts
2. Click on a post title to read the full content
3. Leave comments on posts you enjoy
4. Use the search bar to find specific topics

### Managing Your Blogs

1. Go to "My Blogs" section
2. Edit or delete your posts as needed
3. Track your blog statistics

## 🐛 Troubleshooting

### Blog posts not saving?
- Check browser's local storage settings
- Ensure cookies are enabled
- Clear browser cache and try again

### Styles not loading?
- Check file paths in HTML
- Ensure CSS files are in correct location
- Clear browser cache (Ctrl+Shift+Delete)

### JavaScript not working?
- Check browser console for errors (F12)
- Ensure JavaScript is enabled
- Verify script file paths
